# iCORP MoySkladShop — лендинг

Посадочная страница продукта: готовый интернет-магазин в Telegram для малого и среднего
бизнеса. Учёт товаров, остатков и заказов — на МойСкладе. Страница рассчитана на платный
трафик и принимает заявки прямо в amoCRM.

**Next.js 15 (App Router) · React 19 · без внешних UI-библиотек.**

## Запуск

```bash
npm install
cp .env.example .env.local   # заполнить ключи
npm run dev                  # http://localhost:3000
```

Прод:

```bash
npm run build && npm start
```

## Структура

| Путь | Что внутри |

| `components/` | секции страницы |

## Тексты и переводы

Весь текст лежит в `lib/content.js`: объект `content.ru` и `content.uz` с одинаковой
структурой. Чтобы поправить формулировку — найдите нужное поле и отредактируйте, разметка
и вёрстка не трогаются. Внутри строк работает `**жирный**`.

Язык переключается кнопкой RU/UZ в шапке, выбор запоминается в `localStorage`.
По умолчанию сайт открывается на русском.

## Заявки в amoCRM

Форма отправляет `POST /api/lead`. Маршрут выполняется **на сервере**, поэтому токен
CRM никогда не попадает в браузер.

Что делает маршрут:

1. Проверяет имя и телефон, приводит номер к виду `+998XXXXXXXXX`.
2. Ограничивает частоту — не больше 5 заявок с одного IP за 10 минут.
3. Пишет заявку в лог сервера (страховка: контакт не потеряется, даже если CRM недоступна).
4. Создаёт сделку с контактом через `POST /api/v4/leads/complex`.
5. Добавляет примечание с компанией, комментарием и языком сайта.

### Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `AMO_BASE_URL` | да | адрес аккаунта, например `https://mycompany.amocrm.ru` |
| `AMO_ACCESS_TOKEN` | да | долгосрочный токен интеграции |
| `AMO_PIPELINE_ID` | нет | воронка; не задана — воронка по умолчанию |
| `AMO_STATUS_ID` | нет | этап внутри воронки |
| `AMO_RESPONSIBLE_USER_ID` | нет | ответственный менеджер |
| `AMO_LEAD_TAG` | нет | тег сделки, по умолчанию «Сайт MoySkladShop» |

Токен берётся в amoCRM: **Настройки → Интеграции → ваша интеграция → Ключи и доступы →
Токен долгосрочного действия**.

### Коды ответа `/api/lead`

| Код | Значение |
|---|---|
| `200` | заявка создана, в ответе `leadId` |
| `422` | не заполнено имя или телефон короче 9 цифр |
| `429` | слишком много заявок с одного адреса |
| `503` | не заданы `AMO_BASE_URL` / `AMO_ACCESS_TOKEN` |
| `502` | amoCRM вернул ошибку — подробности в логе сервера |

## Деплой

Нужен Node-сервер: у страницы есть серверный маршрут, поэтому **GitHub Pages не подойдёт**.

- **Vercel** — подключить репозиторий и добавить переменные окружения в настройках проекта.
- **Свой сервер** — `npm ci && npm run build && npm start` под pm2 или systemd, nginx проксирует на порт 3000.

Переменные окружения задаются в панели хостинга, а не в репозитории.

## Что нужно дозаполнить

- **Цены в тарифах** — сейчас во всех трёх стоит «По запросу» (`lib/content.js`, `planPrice`).
- **Превью для соцсетей** — нужен `og:image` 1200×630, пока задан только текст.
- **Счётчик аналитики** — Яндекс.Метрика или Google Analytics.
- **Проверка узбекского текста** носителем языка.
