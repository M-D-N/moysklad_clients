# iCORP MoySkladShop — лендинг

Посадочная страница продукта **iCORP MoySkladShop** — Telegram Mini App для клиентов
[МойСклад](https://www.moysklad.ru/). Страница рассчитана на платный трафик: описывает продукт,
показывает экраны приложения и ведёт на форму заявки.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | вся страница: разметка, стили и скрипт в одном файле, без сборки |
| `brand/` | логотипы iCORP (фавикон и apple-touch-icon) |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |

Внешних зависимостей нет — подключаются только шрифты Google Fonts
(Unbounded, Golos Text, JetBrains Mono).

## Два языка

Русский текст лежит прямо в разметке, узбекский — словарём `UZ` в конце `index.html`.
Переключатель RU/UZ стоит в шапке, выбор запоминается в `localStorage`.
Без JavaScript страница открывается на русском и полностью читается.

Чтобы поправить перевод — найдите нужный ключ в объекте `UZ`. Ключи совпадают с атрибутами
`data-i18n` в разметке.

## Как открыть локально

Достаточно открыть `index.html` в браузере. Либо поднять статический сервер:

```bash
python -m http.server 8080
```

## Публикация

Страница разворачивается как статика где угодно. Для GitHub Pages:
Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)`.

## Что нужно дозаполнить

- **Цены в тарифах** — сейчас во всех трёх стоит «По запросу».
- **Контакты отдела продаж** — в блоке контактов только ссылка на `icorp.uz`.
- **Превью для соцсетей** — нужен `og:image` 1200×630, пока мета-тег не задан.
- **Счётчик аналитики** — Яндекс.Метрика или Google Analytics, чтобы считать трафик с рекламы.

Кнопки «Запросить демо» ведут на <https://icorp.uz/contacts#>.
